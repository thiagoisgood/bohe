# 薄荷健康小程序

一款医疗体重管理微信小程序，提供饮食记录、体重追踪、知识宝典等功能。

## 项目概述

薄荷健康小程序是一个专注于医疗体重管理的微信小程序，帮助用户记录饮食、追踪体重、学习健康知识。

### 核心功能

- **记录页面** - 饮食运动记录和体重追踪
## 📱 功能特性

### 记录页面
- ✅ 首诊信息提示横幅
- ✅ 饮食&运动卡路里统计
- ✅ 快捷记录入口（早餐、午餐、晚餐、加餐、运动）
- ✅ 体重记录与趋势折线图
- ✅ 健康指标卡片（步数、腰围、血糖、血压）
- ✅ 食物搜索弹窗（点击餐次弹出）

### 宝典页面
- ✅ 搜索框和扫描功能入口
- ✅ 知识分类导航
- ✅ 文章列表展示
- ✅ 分类筛选功能

### 我的页面
- ✅ 用户信息展示
- ✅ 功能菜单列表

## 🔧 技术栈

- **框架**：微信小程序原生框架
- **数据**：Mock数据（utils/mock-data.js）
- **样式**：WXSS + CSS变量
- **图表**：Canvas原生绘制

## 🚀 快速开始

### 1. 导入项目

1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择项目目录 `/Users/thiago/program/Show/bohe`
4. 填写AppID（测试阶段可使用测试号）

### 3. 运行预览

在微信开发者工具中点击"编译"即可预览小程序
